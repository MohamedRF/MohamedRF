# Publish your profile README

1. Use a **public** repository named **MohamedRF** under your **MohamedRF** GitHub account.
2. Upload `README.md`, the complete `assets/` folder, and `.github/workflows/snake.yml`, preserving the folder structure. The workflow must be inside `.github/workflows/`, including the leading dot.
3. Commit the files. GitHub displays the README on your profile when the public repository name matches your username.

`preview.html` is a local layout preview generated from the README body. It is not an exact GitHub render and does not need to be uploaded. `SETUP.md` is optional too.

The wave, 28 technology badges, and MRF signature are self-contained SVGs. They require no external fonts or image services. The old activity card has been replaced with a contribution snake generated by GitHub Actions using [Platane/snk](https://github.com/Platane/snk). Light and dark versions match the teal/violet profile colors. GitHub hosts the generated SVGs in your profile repository, on its `output` branch.

The content is a concise paraphrase of the user's LinkedIn About section, read on October 29, 2026. It uses no other LinkedIn sections. ## Start the contribution snake

1. Commit `.github/workflows/snake.yml` to your profile repository's default branch. The automatic push trigger covers `main` and `master`; manual and scheduled runs use the default branch regardless of its name.
2. Open **Actions → Generate contribution snake → Run workflow**. If GitHub asks you to enable Actions for the repository, enable it first.
3. Wait for a successful run. It creates or updates the `output` branch with `github-snake.svg` and `github-snake-dark.svg`; the README then displays the matching version for the reader's theme.

The workflow refreshes daily at **05:47 IST (00:17 UTC)**. GitHub may delay scheduled runs and caches images; inactive public repositories may have scheduled workflows disabled after 60 days. Run it manually to restart updates when needed.

No personal access token or extra secret is needed. The built-in GitHub Actions token fetches the public contribution graph and publishes files within this repository. The job requests `contents: write`; repository or organization policies and rules protecting `output` must permit that push. The workflow uses pinned action revisions, bounded execution, serialized runs, and normal pushes that preserve output history.

The generated SVGs do not exist until the first successful GitHub Actions run. This local workspace is not connected to a GitHub repository, so the live generator has not been run here. The local preview shows the intended image URLs and a first-run note. If you publish under a different repository name, update all three snake image URLs in the README.
